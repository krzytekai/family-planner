# Project Charter — Planer rodzinny

## Produkt
**Planer rodzinny** — rodzinne centrum organizacji dla wielu niezależnych rodzin.

**Designed & developed by Krzytek**

## Zasady
1. Mobile-first i pełna responsywność.
2. Multi-family / tenant isolation od pierwszej wersji.
3. Bezpieczeństwo egzekwowane backendowo i w bazie, nie tylko w UI.
4. Modułowa architektura pozwalająca wymieniać backend.
5. Backup danych z wyborem grup danych.
6. Darmowy/freemium stack na starcie, bez twardego vendor lock-in.
7. Dokumentacja wersjonowana razem z kodem.
