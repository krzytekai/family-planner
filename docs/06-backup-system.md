# Backup System

Administrator/właściciel wybiera zakres kopii:
- profile/członkowie,
- zadania,
- kalendarz,
- zakupy,
- dokumenty,
- budżet,
- pojazdy,
- ustawienia,
- logi aktywności,
- inne moduły dodane w przyszłości.

Backup ma własny manifest wersji formatu. Przywracanie również umożliwia wybór zakresu. Mechanizm ma być niezależny od Supabase na poziomie formatu eksportu.
